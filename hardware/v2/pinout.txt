COMPONENTS  (reference designators)
----------------------------------------------------------------
U1   Raspberry Pi Pico W                  40-pin SMT/THT module
U2   WT901 IMU                            UART, 3V3 power
U3   GY-NEO6MV2 GPS module                UART, 5V power
U4   BME280 breakout                      I2C, addr 0x76
U5   MS4525DO-DS5AI001DP                  I2C, addr 0x28  (A-cal, pitot)
U6   MS4525DO-DS5BI001DP                  I2C, addr 0x36  (B-cal, AOA)
U7   DS18B20 waterproof OAT probe         1-Wire on cable

R1   2.2 kohm     I2C1 SDA pull-up to +3V3
R2   2.2 kohm     I2C1 SCL pull-up to +3V3
R3   4.7 kohm     1-Wire DQ pull-up to +3V3
R4   100  ohm     DS18B20 DQ series, Pico end (optional, cable ESD)

C1   100 nF       U5 VDD-GND decoupling (place < 5 mm from U5)
C2   100 nF       U6 VDD-GND decoupling (place < 5 mm from U6)
C3   100 nF       U7 VDD-GND decoupling at J6 connector

J1   Power input   USB or aircraft regulated 5V  -> VBUS
J2   Pitot port    silicone-hose nipple  -> U5 port "+"
J3   Static port   silicone-hose nipple  -> U5 port "-" (tee'd to U4)
J4   AOA upper     silicone-hose nipple  -> U6 port "+"
J5   AOA lower     silicone-hose nipple  -> U6 port "-"
J6   OAT cable     3-pin connector for U7  (VDD / GND / DQ)
J7   Debug header  unused Pico GPIOs broken out (optional)

PIN-BY-PIN  -  U7  DS18B20 waterproof OAT probe
----------------------------------------------------------------
3-conductor probe cable (typically 1 m, silicone-jacketed):
  Red    (VDD)  ->  +3V3         (U1 pin 36)
  Black  (GND)  ->  GND
  Yellow (DQ)   ->  ONE_WIRE_DQ  (U1 pin 20 / GP15)
                                  via R4 if used
Pull-up:     R3 = 4.7 kohm  from DQ to +3V3
Optional:    R4 = 100 ohm   series on DQ at the Pico end (cable ESD)
Decoupling:  C3 = 100 nF VDD-GND at the J6 connector
Mounting:    probe head in the slipstream (cowl / vent louver /
             NACA scoop); strain-relieve cable at enclosure exit.


----------------------------------------------------------------
LAYOUT NOTES
----------------------------------------------------------------
1.  I2C1 carries three devices (U4, U5, U6).  Add external
    2.2 kohm pull-ups R1/R2 to +3V3.  BME280 breakouts usually
    ship with 10 kohm pulls on board; combined parallel ~1.8 kohm
    is fine for 400 kHz with three devices.  If the breakout has
    stronger pulls, raise R1/R2 to 4.7 kohm.

2.  The MS4525DO has NO address-strap pin.  The I2C address is
    baked into the interface-code letter of the part number.
    Two on one bus REQUIRES two different SKUs:
      U5  = MS4525DO-DS5AI001DP   (A-cal, addr 0x28)  pitot
      U6  = MS4525DO-DS5BI001DP   (B-cal, addr 0x36)  AOA
    If single-SKU sourcing is preferred at layout time, the
    alternates are:
      (a)  Add a TCA9546A I2C mux and put both on its downstream
           channels; reuse 0x28 on both.
      (b)  Split across I2C0 and I2C1.  Move U6 to GP8 (SDA)
           and GP9 (SCL) on I2C0; firmware change is one line.

3.  Place C1 and C2 within 5 mm of the MS4525 VDD pins.  The
    parts are slow but the cap close-in helps the I2C edges.

4.  Route the OAT probe cable away from the GPS antenna feed and
    the WT901 magnetometer axes.  The cable can be 1 m or more.

5.  Leave J7 header broken out on the unused GPIOs so rev B
    doubles as a dev / debug board for the rev-C bring-up.

6.  Static plenum + BMP390 upgrade are explicitly deferred to
    rev C (BOARD-REV-C in BUGS_AND_TODO.md), where the BMP390
    can be reflow-placed on the main PCB with a proper
    PCB-integrated plenum.
