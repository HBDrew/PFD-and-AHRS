# Pi 4 — Preview Screenshots

Screenshots from the Pi 4 version of the PFD with full Synthetic Vision
Terrain (SVT) rendered via OpenGL.

## Regenerating

These PNGs are checked into git so the user manuals render correctly on
GitHub.  To regenerate them after a UI / scene change, run on the pi4:

```bash
./tools/regen_previews.sh pi4
```

That wraps `tools/capture_pi4_previews.sh`, which uses the offline GL
renderer (`pi4/render_pfd_offline.py`) with `SDL_VIDEODRIVER=dummy` +
an offscreen EGL context so the captured PNGs include the full 3D SVT
terrain.  Must be run on a pi4 (needs the V3D driver).  The script
stops `pfd.service` for the capture session and brings it back on exit.
(The same build runs on a **Pi 5** — capture there too if that's your
flying hardware.)

## New-feature previews (referenced by the manual)

| File (in `pfd_gl/`) | Source | Notes |
|---|---|---|
| `preview_flight_path_vector.png` | **offline tool** (`SCENES` + `_setup_flight_path_vector` in `render_pfd_offline.py`) | regenerated by `regen_previews.sh pi4` — no live data needed |
| `preview_winds.png` | **live capture** | WND overlay needs real winds data — see below |
| `preview_metar.png` | **live capture** | MET overlay needs live METARs |
| `preview_traffic.png` | **live capture** | needs live/replayed ADS-B traffic |
| `preview_mfd.png` | **live capture** | full-screen MFD (3-finger swap), any overlay |

**Live capture** (the offline renderer has no live weather/traffic feeds, so
these four are grabbed from the running display instead): with the app running
and the internet feeds up, switch to the page you want (OVLY → WND / MET / TFC,
or 3-finger-swap to the MFD), then save a framebuffer grab to the matching
filename, e.g.:

```bash
# on the running pi4/pi5, capture the current framebuffer:
fbgrab ~/PFD-and-AHRS/pi4/previews/pfd_gl/preview_winds.png    # WND page up
fbgrab ~/PFD-and-AHRS/pi4/previews/pfd_gl/preview_metar.png    # MET page up
fbgrab ~/PFD-and-AHRS/pi4/previews/pfd_gl/preview_traffic.png  # TFC page, traffic in view
fbgrab ~/PFD-and-AHRS/pi4/previews/pfd_gl/preview_mfd.png      # full-screen MFD
```

(`sudo apt install fbgrab` if needed; or use the sim + the internet feeds for
repeatable framing.)
